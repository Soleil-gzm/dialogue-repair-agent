# 公开轨分布校准（realistic profile）

## 为什么做

原来的公开轨 `base_v1` 只有一个很窄的生成参数：每条对话 3–7 轮、system 约 142 字、
assistant 回复几乎不复用。它适合做冻结基线，但不代表真实工作数据的形状，
因此无法回答“Agent 在更长的多轮对话、更多重复话术、更高实体密度下还成不成立”。

本轮从私有轨的 1000 条对话中只提取**聚合统计**，用这些统计校准公开 generator。
不复制原文、不复制业务标签、不复制客户信息，也不把私有文件带进开源仓库。

## 提取了什么

| 维度 | 私有轨聚合值 | 校准方式 |
|---|---|---|
| 轮次 | 1–26 轮，中位 11，均值 10.85；消息 3–53 条 | `REALISTIC_TURN_HISTOGRAM` + 最大余数分配 |
| assistant 唯一率 | 49.53%（去数字后全局唯一） | 受控复用率 50.47% |
| user 唯一率 | 28.51%（去数字后全局唯一） | 非首轮复用率 79%，补偿首轮强制新建 |
| 对话内 assistant 重复 | 33/1000（3.3%） | 3.3% 概率复制一条非相邻 assistant |
| system 长度 | 348–375 字，均值 361 | 固定模板，生成 363–365 字 |
| user 长度 | 中位 13，均值 15.1，p95 31 | 8×8×24×8 短句组合 |
| assistant 长度 | 中位 47，均值 56.1，p95 120 | 3/4 段话术组合 |
| 实体密度 | 100% system 含金额；无订单号；assistant 无 system 外编号 | system 含金额与案件号；assistant 不生成编号/金额 |

## 怎么实现

- `agent/benchmark/profiles.py`：只放聚合参数与目标区间，不放任何私有文本。
- `agent/benchmark/realistic.py`：
  - 轮次用直方图做最大余数分配，`n=1000` 时精确复现私有轨直方图；
  - 复用池按目标唯一率抽样，复用前排除当前对话已有文本，避免制造相邻重复；
  - 首轮 user 强制新建并带 `CASE-xxxxxx`，保证 D2（指代断裂）仍有可注入实体；
  - 3.3% 的对话复制一条**非相邻** assistant，复现“对话内重复”但不制造相邻高相似；
  - system 固定含金额与案件号，assistant 不生成 system 外编号或金额。
- `agent/benchmark/fixtures.py`：新增 `--profile realistic`，默认仍是 `v1`。
  `v1` 的生成逻辑与产物保持不变，`baseline_lock.json` 不受影响。
- 分层切分：校准档使用覆盖 1–26 轮的 `REALISTIC_TURN_BUCKETS`，v1 继续用原桶。

## 复现

```bash
# 120 条公开校准基线
python -m agent.benchmark.fixtures --profile realistic

# 40 + 80 分层切分
python -m agent.benchmark.fixtures --profile realistic \
  --dev-out agent/fixtures/public/realistic_dev_v1.json \
  --test-out agent/fixtures/public/realistic_test_v1.json

# 校准门禁
python -m pytest agent/tests/test_fixture_profile.py -q
```

## 结果

| 指标 | v1 base（12 条） | realistic base（120 条） | realistic 校准跑（1000 条） | 私有轨目标 |
|---|---:|---:|---:|---:|
| 轮次中位 | 4 | 11 | 11 | 11 |
| 轮次均值 | 4.67 | 10.82 | 10.85 | 10.85 |
| 消息范围 | 7–15 | 3–47 | 3–53 | 3–53 |
| assistant 唯一率 | 10.7% | 52.2% | 49.3% | 49.5% |
| user 唯一率 | 21.4% | 30.5% | 28.3% | 28.5% |
| 对话内重复率 | 8.3% | 1.7% | 2.9% | 3.3% |
| system 长度 | 142 | 364 | 363–365 | 348–375 |
| assistant 长度中位 | 17 | 48 | 48 | 47 |
| user 长度中位 | 13 | 14 | 15 | 13 |

小样本的唯一率与重复率会自然波动；门禁测试以 1000 条校准跑为准，
并允许“生产数据的聚合分布本来就有波动”这一事实。

## 边界

- 校准的是**分布形状**，不是真实文本。公开轨仍然是合成数据，不能替代生产抽检。
- 唯一率按“去数字后全局唯一文本数 / 总消息数”计算；与私有轨统计口径一致。
- 复用池、话术池都是中立域售后回访文本，与私有业务无关。
- 该 profile 目前只用于生成公开 fixture 与校准测试，不改变已冻结的 A0 基线。
