## 0. 先回答一个问题：为什么不能只报一个胜率

假设 A3 在 50 条样本上赢了 30 条，胜率 60%。这个 60% 至少有三个问题：

1. **抽样噪声**：换一批 50 条，可能变成 52% 或 68%。点估计本身不携带"有多确定"的信息。
2. **怎么算赢**：平局算不算？没跑完的算不算？分母不同，胜率可以差出十几个点。
3. **是不是撞运气**：两个方法在 50 条上的差异，可能纯由"这 50 条恰好适合其中一个"造成。

下面四个工具分别解决其中一个问题。

---

## 1. 胜率区间（Wilson 95% CI）

### 是什么

胜率是一个比例。给比例配一个区间，表示"如果重复抽样，95% 的区间会覆盖真实值"。

Wilson 区间比常见的"正态近似"更稳，因为它在 p 接近 0 或 1、样本量小时不会算出负数或超过 100%。

### 怎么算（不用手算，记住直觉）

n=50、赢 30 条：

```
点估计 p = 30/50 = 60%
Wilson 95% CI ≈ [46%, 72%]
```

区间宽度由样本量决定：n 越大越窄。**n=50 的区间大约 ±13 个百分点**，所以：

- 报"胜率 60%"没有信息量；
- 报"胜率 60%，95% CI [46%, 72%]"才说明：真实值可能低到 46%，不能宣称"过半"。

### 本项目的用法

- 主指标同时报：`WR = W/(W+L+T)`、`WR_decided = W/(W+L)`、`tie_rate`。
- 原因：tie 多的时候，`WR` 会被拉低；只看 `WR_decided` 又会掩盖"大量判不出差别"这一事实。两个都报，读者自己判断。

### 常见错误

- 拿两个区间"是否重叠"判断显著性。区间重叠 ≠ 不显著，正确做法是配对检验（见第 2 节）。
- 用 n=50 宣称"提升 5 个百分点"。样本量根本支撑不了这个精度（见第 4 节）。

---

## 2. McNemar 配对检验

### 解决什么

同一批对话，分别给方法 A 和方法 B 处理，关心"A 比 B 好吗"。因为每条样本被两个方法各处理一次，这是**配对**数据。

McNemar 只看**不一致的对**：

| | B 赢 | B 没赢 |
|---|---|---|
| **A 赢** | a（都赢，无信息） | b（A 赢 B 没赢） |
| **A 没赢** | c（B 赢 A 没赢） | d（都没赢，无信息） |

检验统计量（含连续性校正）：

```
χ² = (|b - c| - 1)² / (b + c)
```

b+c 很小时（比如 < 25），用精确二项检验代替 χ²。

### 例子

50 条样本：A 赢 20 条、B 赢 5 条、其余 25 条打平或都失败。

```
b = 20, c = 5
χ² = (15 - 1)² / 25 = 7.84
自由度 1，p ≈ 0.005
```

结论：在 α=0.05 下拒绝"两者无差异"。注意：**a 和 d 完全不进入计算**，这是 McNemar 和普通卡方的关键区别。

### 为什么必须配对

如果两组样本不同（比如 A 用 test_v1、B 用 dev_v1），样本难度差异会混进结果，McNemar 不适用。这也是 Benchmark 设计里 R1/R2 要求"同一输入、同一抽样键集合"的统计学原因。

### 常见错误

- 把"每条样本的分数"当连续变量做 t 检验。胜率是二分类，t 检验的分布假设不成立。
- 忘记连续性校正，或 b+c 很小时仍用 χ² 近似。

## 3. 双向盲评（A/B 与 B/A）

### 解决什么

LLM judge 或人工评分时有三种系统性偏差：

| 偏差 | 表现 |
|---|---|
| 位置偏差 | 总是偏好放在前面的那份 |
| 长度偏好 | 总是偏好更长的那份 |
| 自我偏好 | 偏爱与自己风格相近的输出 |

### 怎么做

1. judge 不知道哪份来自实验臂，只看到"对话 1 / 对话 2"。
2. 同一对样本评两次：第一次 A 在前 B 在后，第二次 B 在前 A 在后。
3. 两次结论矛盾 → 记为 tie，而不是取平均或取第一次。

### 为什么矛盾要记 tie

两次结论相反，说明 judge 的判断不稳定，或者两份质量确实接近。强行选一个会把噪声包装成结论。记 tie 虽然降低表观胜率，但这是诚实的做法。

### 配套控制

- rubric 明写"不因更长而加分"；
- 报告附 `winner 长度均值差`，让读者看到长度偏差是否仍然存在；
- judge 与生成模型跨家族（见 ADR D4）；做不到时必须在 limitations 声明。

## 4. 人工校准（Cohen's κ 与一致率）

### 解决什么

LLM judge 的分数不能直接当真理。需要一小批人工标注做"尺子校准"：judge 和人的判断有多一致？

### 两个指标

**一致率（agreement）**：人和 judge 判断相同的比例。简单，但会被"类别不平衡"骗。比如 90% 样本都是"没问题"，judge 全判"没问题"也能有 90% 一致率。

**Cohen's κ**：扣掉"碰巧一致"之后的一致性。

```
κ = (Po - Pe) / (1 - Pe)

Po = 实际一致率
Pe = 按两边各自的比例，随机判断时 expected 一致率
```

经验阈值（Landis & Koch）：

| κ | 解释 |
|---|---|
| < 0.40 | 一致性差，judge 不可用 |
| 0.40–0.60 | 中等 |
| 0.60–0.80 | 较好（本项目目标 ≥ 0.6） |
| 0.80–1.00 | 很好 |

### 本项目的用法

- 从 test 集抽一小批（如 30–50 条），人工按 4 维 rubric 打分；
- 报 `judge-人工一致率` 与 `κ`，两者都进报告；
- κ 不达标时，胜率结论降级为"参考"，不作为主结论。

---

## 5. 样本量：n=50 能说明什么

配对二分类比较（McNemar，α=0.05，power=0.8）的近似需求：

| 想检出的胜率差 | 需要 n |
|---|---|
| 20 个百分点 | ≈ 50 |
| 15 个百分点 | ≈ 90 |
| 10 个百分点 | ≈ 200 |
| 5 个百分点 | ≈ 800 |

**结论：n=50 只支撑"≥15–20 个百分点"级别的结论。**

所以本项目的正确表述是：

- ✅ "A4 相对 A3L 的阻断率从 83.3% 提升到 100%，差异幅度足够大"；
- ❌ "A3R 比 A3 好 5 个百分点"（n=50 下这在统计上不可区分）。

### 四个术语的关系（一句话版）

| 工具 | 回答的问题 |
|---|---|
| Wilson 区间 | 这个比例本身有多确定 |
| McNemar | 两个配对方法的差异是不是撞运气 |
| 双向盲评 | 评分过程有没有被位置/长度/自我偏好污染 |
| 人工校准 | judge 这把尺子准不准 |

四者缺一不可：只报区间不做检验，无法下"更好"的结论；只做检验不控偏差，检验的是一个有偏的指标；不校准 judge，整条链的测量基础就不成立。
