# 文档归档与版本追溯

本目录只存放**不再作为现行依据**的历史文档。归档文件保持原样（含原始版本号与日期），不再修改；如需继续演进，必须在现行目录另建新版本，并在下表登记。

## 1. 归档判定标准

满足任一条件即归档：

1. 文档的整体结论已被新的设计文档替代；
2. 文档中的日期计划、阶段划分与实际执行体系冲突；
3. 文档内容已按主题合并进现行文档，单独保留会产生重复或冲突。

归档不等于删除：原文用于追溯“当时的判断是什么、后来为什么改”。

## 4. 版本记录规则

- 归档文件只读，文件名保留原名，目录名格式为 `v<版本>-<日期>`。
- 现行文档在文首维护“版本 / 最后修订 / 关联文档”；发生实质修订时更新版本号。
- 新增归档必须在第 2 节表格追加一行，写明替代文档。
- 与 `agent/benchmark/baseline/lock_changelog.md` 同理：变更留痕，不静默覆盖。
